# CV Antonio Oyuela — Astro

## Ejecutar
```bash
npm install
npm run dev
```
Abre http://localhost:4321.

## Compilar
```bash
npm run build
npm run preview
```

El botón «Guardar CV en PDF» abre la impresión del navegador. Selecciona «Guardar como PDF».
Edita `src/pages/index.astro` para cambiar los datos, cursos, enlaces y proyectos.
